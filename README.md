# AI Confusion Detector

AI Confusion Detector is an AI-based learning support system designed to identify signs of student confusion during learning and provide helpful explanations, suggestions, and guidance.

## Features
- Detects possible student confusion
- Provides personalized learning support
- Gives explanations and suggestions
- Helps students understand difficult concepts
- Simple and student-friendly interface

## Technologies
- HTML
- CSS
- JavaScript
- Python
- AI/ML
